# Code of Conduct

Smart Paste follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful. Welcome people of every background and experience level. Give and take feedback
gracefully, and keep discussions about the work. Harassment of any kind is not accepted.

The code applies in every project space (issues, pull requests, and discussions) and wherever you represent the
project.

## Reporting a problem

If someone's behavior breaks this code, please tell the maintainers privately:

1. Open the repository's [Security tab](https://github.com/vtikyani/smart-paste/security) and click
   **Report a vulnerability**. Only the maintainers can see what you send there.
2. Start the title with "Code of conduct", and describe what happened, where, and when. Links help.

You can also report a comment, issue, or pull request to GitHub itself: open its **...** menu, choose
**Report content**, then **Report abuse to GitHub Support**.

The maintainers will review every report, keep it confidential, and act on it as the Contributor Covenant's
enforcement guidelines describe.
